# Konsultacje psychologiczne: rezerwacja wizyt

Aplikacja do rezerwacji konsultacji psychologicznych, tworzona na zajęciach
„Projektowanie aplikacji webowych” (SWPS).

## Uruchomienie

    python -m venv .venv
    pip install -r requirements.txt
    python hello.py

## Planowane funkcje

- przeglądanie listy specjalistów
- rezerwacja wizyty
- opinie po wizycie
- przypomnienia e-mail o wizycie
- panel administratora

## Technologie

- [Python](https://www.python.org/): język programowania
- [Django](https://www.djangoproject.com/): framework webowy (**od labu 3**)
- [git](https://git-scm.com/) i [GitHub](https://github.com/): kontrola wersji
